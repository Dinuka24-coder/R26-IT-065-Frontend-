# PulmoAI Frontend

Complete React + Vite frontend mock UI for a Multi-Model Pulmonary Disease Detection System.

## Users

- Doctor
- Administrator

## Features

- Login page
- Dashboard
- Patient search
- Patient registration
- X-ray model selection
- X-ray upload workflow
- Pneumothorax, Pneumonia, TB result views
- CT lung cancer classification result view
- Prediction history
- Reports
- Admin panel

## Setup

```bash
npm install
npm run dev
```

Open:

```text
http://localhost:5173
```
